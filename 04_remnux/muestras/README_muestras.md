# Inventario de muestras

Las cinco muestras fueron generadas localmente para esta práctica. Son benignas, no se descargaron de repositorios externos y no se ejecutaron. La marca YARA del archivo TXT y el patrón JSON fueron añadidos intencionalmente para validar reglas de demostración.

- M01: muestra_01_texto.txt - Texto benigno creado localmente; contiene una marca intencional para una regla YARA de demostración.
- M02: muestra_02_datos.json - JSON benigno creado localmente; contiene campos de laboratorio para una segunda regla YARA.
- M03: muestra_03_registros.csv - CSV benigno creado localmente con dos filas de datos ficticios.
- M04: muestra_04_paquete.zip - Archivo ZIP benigno creado localmente; contiene únicamente LEEME.txt.
- M05: muestra_05_script_inerte.py - Archivo de texto con comentarios; no se ejecutó y no contiene acciones.
